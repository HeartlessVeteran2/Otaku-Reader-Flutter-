# Not a package. The record of what was measured before adopting AnymeX's
# extension bridge, so the next reader does not repeat the resolution spike.
#
# Read CLAUDE.md -> "The extension bridge" for the decision this supports.
# The short version: the bridge is ADDITIVE. lib/source/ stays.

# ── 1. The combination that resolves, keeping lib/source/ ──────────────────
# This is this app's real pubspec with three edits. It was applied in place and
# verified end to end; the pins were then REVERTED, because a d4rt downgrade
# buys nothing until the bridge actually lands.
#
#   - isar_community / isar_community_flutter_libs : ^3.3.2  ->  3.3.0-dev.3
#   - isar_community_generator (dev)  : Mangayomi's git fork ->  3.3.0-dev.3
#   - d4rt                            : ^0.2.4              ->  0.1.7
#   + anymex_extension_runtime_bridge :
#         git:
#             url: https://github.com/RyanYuuki/AnymeXExtensionRuntimeBridge.git
#             ref: 62df59fab5b74968cc68c70ddc9c1570050e316f
#
# Pin the ref to a commit, never `main`: this is a third-party plugin that
# runs third-party code, and AnymeX's own pubspec tracking `main` is not a
# reason for this app to.
#
# The conflict everyone hits is NOT d4rt. It is Mangayomi's
# isar_community_generator fork, which wants analyzer ^8.4.0 while d4rt <0.2.0
# wants ^7.4.5. Swapping the fork for the published generator of the same
# version removes it; d4rt 0.1.7 then resolves against the bridge's own pin.

# ── 2. lib/source/ on d4rt 0.1.7 — one line ────────────────────────────────
# 0.2.4 deprecated `args: Object?` for `positionalArgs: List<Object?>`. 0.1.7
# has only `args`, and wraps a single object into [args] itself, so:
#
#   -  positionalArgs: [source.toMSource()],
#   +  args: source.toMSource(),
#
# in lib/source/runtime/dart_source_runtime.dart, and nothing else across the
# 17 files that import d4rt. The BridgedClass surface is identical between the
# two versions -- checkable directly, since the bridge's own
# Eval/dart/bridge/*.dart and this app's are ports of the same upstream.
#
# Verified on those pins:
#   flutter analyze                 clean
#   build_runner                    output identical but for the `version:`
#                                   string stamped into each schema
#   flutter test                    512 passing
#   flutter test tool/source_sweep  evaluated 55/55, popular 8,
#                                   detail+chapters 6, full chain 6
#                                   -- the baseline, exactly
#   + the bridge as a git dependency:
#   flutter pub get                 resolves, no dependency_overrides
#   flutter analyze                 clean

# ── 3. The four combinations that do NOT resolve ───────────────────────────
#   1. bridge + isar_community ^3.3.2       -> the bridge pins 3.3.0-dev.3 exactly
#   2. bridge + Mangayomi's generator fork  -> ^3.3.0 excludes pre-releases
#   3. + override isar to dev.3             -> the bridge pins d4rt 0.1.7 exactly
#   4. + override d4rt to 0.1.7             -> analyzer ^7.4.5 vs the fork's ^8.4.0

# ── 4. The Android side does not build as-is ───────────────────────────────
# `flutter build apk --debug` with the bridge added fails three times, each on
# a plugin pinned to a 2022-era toolchain:
#
#   device_apps 2.2.0    jcenter() (gone in Gradle 9), AGP 4.0.1 classpath,
#                        compileSdkVersion 30. Abandoned; 2.2.0 is latest.
#                        Used ONLY by AniyomiExtensions: isAppInstalled,
#                        uninstallApp.
#   install_plugin 2.1.0 no namespace, compileSdkVersion 28, AGP 7.3.0
#                        classpath. Abandoned. One method: installApk.
#   file_picker          compiled against android-34 -- this repo's own root
#                        Gradle hook was silently losing to it. Fixed with
#                        androidComponents.finalizeDsl.
#
# With a stub standing in for each of the first two, the debug APK BUILDS.
# Both are Aniyomi-only, so writing real replacements is slice 2's work.
#
# Carried in regardless of what this app calls: libtorrent_flutter (12.3 MB of
# native torrent library PER ABI), flutter_inappwebview 6.2.0-beta.2, jni,
# file_picker, QuickJS (libqjs.so). Debug APK measured 198.9 MB -> 239.9 MB.
